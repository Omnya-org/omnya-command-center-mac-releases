# Omnya Command Center for Mac: releases

Internal tool for Omnya's team. Not for customers.

This repo only holds the signed, notarized installers and the update feed (`appcast.xml`) the app checks for updates. Source: the private repo Omnya-org/omnya-command-center-mac.

Install: download `Omnya-Command-Center.dmg` from the latest release, drag the app to Applications, open it and sign in with your Omnya Google account. It updates itself after that.
